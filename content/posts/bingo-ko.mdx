우리 회사에서는 매년 케미데이를 엽니다. 케미데이는 회사 구성원분들끼리 삼삼오오 모여 케미를 다지는 특별한 행사인데요. 팀원끼리 무엇을 할 지 정해서 반나절 정도 시간을 보내는 야유회라고 생각해주시면 됩니다. 우리 팀에서도 여러 아이디어를 후보로 올렸고, 저도 한 아이디어를 슬며시 올렸습니다.

> 팀 내 케이데이 아이디어 후보

| 콘텐츠명                               | 상세 내용                                 |
| ---------------------------------- | ------------------------------------- |
| 조별 베스트샷 대항전                        | 둘레길 지정 포토존에서 특정 포즈로 단체 사진 촬영          |
| 애장품 교환식                            | 서로의 애장품을 추첨을 통해 교환                    |
| 팀별 릴레이 산보 마라톤                      | 구간별로 팀원이 배치되어 끝까지 빠르게 가는 팀 경기 미션      |
| 직녀와 견우                             | 사전에 2명씩 랜덤으로 위치 + 짝 지어서 소개팅 (친해지길 바래) |
| 1초 브이로그 만들기                        | 사전에 랜덤으로 팀을 꾸려서 케미데이를 즐긴 후 1초 브이로그 제작 |
| 케이뱅크산악회 - 패션대회                     | 제일 등산객처럼 입고 온 사람을 선정하여 선물 증정          |
| [위치기반 빙고](/side-project?tab=bingo) | 9개의 장소를 방문하여 빙고 맞추기                   |
제가 올린 아이디어는 [위치기반 빙고](/side-project?tab=bingo)입니다. 게임의 룰은 빙고와 동일합니다. 다만 빙고 칸에 숫자나 주제 대신 위치를 표시했어요. 스마트폰을 가지고 각 위치에 가까이 다가가면 칸을 채울 수 있습니다. 각 참여자는 모두 동일한 9개의 장소 칸을 가지게 되는데, 위치는 모두 랜덤이에요. 이를 먼저 채우는 사람이 우승하는 게임입니다.

![장충동 산책로 지도 곳곳에 표시한 빙고 위치](/images/bingo-map.webp)

주최측에서 야유회를 3시간 정도로 기획하고 있어서, 제 아이디어가 적절했는지 연락을 주셨습니다.
